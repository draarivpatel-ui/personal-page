# Aariv Patel - Personal Drafting Board

Personal website and technical portfolio for Aariv Patel, styled after a Swiss architectural drafting sheet. Built for the Hack Club Stardance "Personal Site" mission with zero external frameworks or runtime dependencies.

![Aariv Patel personal drafting board](screenshot.png)

Live: https://aariv.me/personal-page/

## What is on the sheet

1. **01 // Identity & Spec (`#about`)**: Overview of my work as a freshman at Dulles High School, founder of the Digital Design Club, and builder of open-source developer tools and pro-bono community nonprofit websites, paired with a geometric SVG monogram (`a.`) and specification table.
2. **02 // Projects & Systems (`#projects`)**: Interactive, filterable index of six shipped builds (`Regatta`, `wasitme`, `AarivOS`, `Pulse`, `Devlog Timer`, and `Garlic Panic`) with category filters (`All`, `Developer Tools`, `Web Systems`, `Games`), architecture notes, live demos, and source repository links.
3. **03 // Design, Speaking & Tabla (`#craft`)**: How interface critique at the Digital Design Club, pro-bono web studio work for student and community groups like MSA, competitive speech and debate, and classical North Indian tabla practice shape how I write software. Includes an interactive 16-beat *Tintal* cycle (`4 + 4 + 4 + 4`) matra stepper.
4. **04 // Colophon & Setup (`#colophon`)**: Live color token swatches (`Dark Draft` obsidian slate and `Daylight Paper` warm vellum), typography specification, and single-key navigation controls (`1-4` section jump, `t` theme toggle, `f` filter cycle, `m` tabla matra step).

## Running locally

Open `index.html` directly in any browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

## Why I built this

I had shipped six separate tools, games, and web systems across my repositories, plus a pro-bono studio site for community nonprofits, without a single home page that connected the software to the rest of what I care about: typographic grids at the Digital Design Club, structured argument in speech and debate, and rhythmic cycles on the tabla. Designing this page as a Swiss drafting board let me put every project, specification, and keyboard shortcut on one fast, zero-dependency sheet.
